# ⚡ GenLayer Intelligent Consensus Spinner

A production-grade, ultra-performant Web3 loading component tailored for the **GenLayer** ecosystem. It visually demonstrates real-time decentralized validator discovery, peer-to-peer neural synchronization, and intelligent contract execution.

---

## 🌟 Visual Metaphor & Concept

* **Neural Consensus Core:** A central pulsing node and rotating hexagonal matrix representing GenLayer's intelligent smart contract execution engine.
* **Multi-Tier Validator Orbits:** Three counter-rotating orbital tiers with traveling nodes representing decentralized validators.
* **Dynamic Peer-to-Peer Mesh:** Real-time dynamic distance calculations draw active communication links between adjacent validator nodes.
* **Cyberpunk Glassmorphism UI:** Built with dark cyber gradients (violet `#8b5cf6`, cyan `#22d3ee`, fuchsia `#e879f9`) and smooth glow filters.

---

## ✨ Features

* **Zero External Dependencies:** Built entirely with native HTML5, SVG, and CSS3 animations.
* **60+ FPS Hardware Accelerated:** Highly optimized for mobile and desktop GPU rendering, featuring pre-allocated SVG pools to prevent runtime Garbage Collection (GC) frame drops.
* **Interactive 3D Parallax:** Responsive mouse-tracking and mobile touch-drag parallax tilt.
* **Accessibility First:** Includes native `@media (prefers-reduced-motion)` fallbacks.
* **Framework Agnostic:** Easily dropped into vanilla JavaScript, React, Next.js, or Vue projects.
